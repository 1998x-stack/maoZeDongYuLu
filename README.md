# 《毛主席语录》整理资料 · 文献阅读与内容核对

基于本仓库 `jsons/` 现有整理文本构建的静态阅读器：按篇章浏览、逐条检索、查看来源文字和原始 JSON 位置，并可生成分页 PNG 文献卡片。本项目用于历史资料阅读与核对，不对文本表达的政治观点作评价。仓库文本、归属和出处**尚未进行逐条独立版本校勘**。

## 阅读方式

- **逐条阅读**：正文篇章按仓库原有顺序排列。目录和另有署名的再版前言作为附属资料单列，不计入正文记录，也不作为毛泽东原文导出。
- **全文检索与筛选**：搜索正文、出处、篇章名称和整理分类；可同时按章节和“附有出处文字／未单独标注出处”筛选。筛选表示仓库内字段状态，**不等于出处经核验**。
- **回到原始资料**：每条记录显示章内顺序号、`chapter_id:block:record` 定位、JSON 文件名和 `contentList` 原始下标，点击“查看原始 JSON”可复核上下文。该记录 ID 仅保证**当前解析规则与数据快照内**的定位；将来更改原始文本或分段规则时可能变化。
- **复制与卡片**：支持复制正文、复制正文和整理出处；独立 Canvas 工作台提供三种中性版式、3:4／4:5／1:1 图片比例、字号调节、长文自动分页和本地 PNG 下载。长出处在图片上明确提示回到阅读页，不假装在卡片中展示了全部来源。
- **资料概况与说明**：页面说明记录数口径、出处字段性质以及为什么某些内容需要人工核对。所有数量只代表**本仓库整理文本在当前解析规则下**的结果，不代表历史文本总数或不同版次的标准段落数。

## 为什么不能直接按 contentList 数组统计

仓库中的 `contentList` 一项可能同时包含数段正文及各自的出处。一些来源行以 `——` 开头；部分直接以 `《作品》` 开头；还有部分以“在……讲话／谈话”等活动描述开头。旧版只认第一类，造成部分书目文字混入正文，甚至将多段文字合成同一条结果。本版采用保守的格式识别拆分，不会从章节标题推断发表日期、原文网址或原始版次；无法可靠判断的格式需要人工标记。独立来源说明（如校训来源）与书目条目也应在后续校勘中进一步区分。

**重要：** 当前各 JSON 的 `analysisList` 中有大量模板化的“核心观点阐述＋字数”占位内容；这些不是经过核实的研究性解读，因此网站不把它们展示为专家分析，也不会将其写进分享卡片。若需要更丰富的历史背景，应先为每条文字建立可核对的出版信息、上下文和独立参考资料，然后将资料引文与编者说明分开展示。

## 内容审计与进一步校勘

```bash
node scripts/audit-content.mjs
```

脚本按章输出解析记录数、识别到的来源文字、未识别来源、非书目来源说明、不规范书名号以及模板式 `analysisList` 的数量，疑点附原始文件与 `contentList` 定位。**审计脚本通过或“未识别来源数为 0”只表示程序识别到了相应文本行，不代表原始内容、署名、出处或日期真实准确。**

检查流程、已观察到的数据边界、人工校勘字段设计及发布验收标准见 [内容审计与编辑工作流](docs/CONTENT_AUDIT.md)；系统架构见 [技术设计](docs/ARCHITECTURE.md)。原始 `jsons/` 整理文本没有在本次升级中被自动改写。

## 本地运行

网站没有 npm 运行依赖和远端图片生成服务。需要现代浏览器和支持 ES Modules 的本地 HTTP 服务：

```bash
git clone https://github.com/1998x-stack/maoZeDongYuLu.git
cd maoZeDongYuLu
python3 -m http.server 8000
```

访问 `http://localhost:8000/`。直接以 `file://` 打开页面可能因浏览器安全限制而无法读取相邻 JSON 文件。

使用 Node.js 22 进行语法检查、真实语料回归测试和内容审计：

```bash
node --check src/app.mjs
node --check src/corpus.mjs
node --check src/card.mjs
node --check scripts/audit-content.mjs
node --test tests/*.test.mjs
node scripts/audit-content.mjs
```

PR 上的 CI 执行相同检查。`main` 部署工作流在通过校验后，仅发布 `index.html`、`styles.css`、`content.css`、`src/` 和 `jsons/`；校勘文档及脚本不进入静态站点。

## 目录结构

```text
index.html                     阅读页面、筛选控件及图片工作台
styles.css / content.css       基础阅读样式与出处/审计说明层级
src/app.mjs                    加载、检索、原始文件定位、复制与工作台交互
src/corpus.mjs                 语料清单、分段、来源格式识别和筛选
src/card.mjs                   Canvas 卡片排版、分页与本地 PNG 下载
jsons/                        原有 35 份编号 JSON 与独立 metadata.json
scripts/audit-content.mjs      可复现的内容审计及人工核对定位
 tests/                        真正使用仓库内容的回归测试与合成边界样例
.github/workflows/             PR 内容校验与 GitHub Pages 部署
```
