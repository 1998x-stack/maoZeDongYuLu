# 毛主席语录网页版

基于 JSON 数据生成的交互式《毛主席语录》阅读网页。

## 功能特性

### 📚 章节导航
- **分类浏览**：左侧导航栏按分类（如"党的建设"、"军事"等）组织章节
- **快速跳转**：点击章节按钮立即加载内容
- **视觉反馈**：当前选中章节高亮显示

### 🔍 智能搜索
- **全文搜索**：实时搜索所有章节内容
- **高亮结果**：显示匹配的语录及其所在章节和分类
- **搜索统计**：显示搜索结果数量

### 🎨 设计特色
- **Claymorphism 风格**：软萌的3D效果，圆润边角
- **响应式设计**：适配桌面、平板和手机
- **无障碍支持**：语义化HTML、ARIA标签、键盘导航
- **性能优化**：懒加载、防抖搜索、平滑过渡

### 💡 用户体验
- **视觉层次**：清晰的标题、引用文本和来源区分
- **交互反馈**：悬停效果、点击动画
- **阅读友好**：经典字体、舒适行距、合理留白

## 技术实现

### 设计系统
- **设计模式**：Feature-Rich Showcase
- **视觉风格**：Claymorphism（软萌3D）
- **配色方案**：
  - 主色：#4F46E5 (靛蓝)
  - 辅色：#818CF8 (浅蓝)
  - 强调色：#F97316 (橙红)
  - 背景：#EEF2FF (淡紫)
- **字体**：Cormorant Garamond + Libre Baskerville (经典衬线)

### 前端技术
- **纯HTML/CSS/JavaScript**：无依赖，轻量快速
- **现代CSS**：自定义属性、Flexbox、Grid、Backdrop-filter
- **渐进增强**：即使JavaScript失败也能显示基本内容

## 使用方法

### 本地运行

1. **启动HTTP服务器**（必需，因浏览器安全限制）：

```bash
# 在项目根目录运行
python3 -m http.server 8000
```

2. **访问网页**：
打开浏览器访问 `http://localhost:8000`

## 开发说明

### 数据加载
- 自动扫描 `jsons/` 目录下的所有章节文件
- 按 `classify` 字段分组显示
- 支持动态添加新章节

### 搜索功能
- 实时搜索（300ms防抖）
- 支持跨章节搜索
- 显示搜索结果所在的章节和分类

### 样式定制
所有样式使用CSS自定义属性，可通过修改 `:root` 中的变量调整：

```css
:root {
    --primary: #4F46E5;    /* 主色 */
    --secondary: #818CF8;  /* 辅色 */
    --cta: #F97316;        /* 强调色 */
    --bg: #EEF2FF;         /* 背景色 */
    --text: #1E1B4B;       /* 文字色 */
}
```
