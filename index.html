ABOUT THIS COLLECTION

怎样理解这些记录

本页是对仓库内 JSON 整理文本的浏览，不是经过逐字校勘的权威版本，也不是对全部历史文献的抽样统计。内容保留原整理文本的措辞和标点；自动拆分只帮助定位，不补写缺失出处。

原资料与整理记录

“整理记录”是按仓库中正文及相邻出处行拆分的阅读单位。一个原始 JSON 字符串可能含多条记录；目录与另有署名的再版前言单列为附属资料。

“有出处”不等于“已核实”

出处文字来自当前整理文件，尚未逐项与指定版次或原始出版物比对。缺少独立出处时会明确标记，不从章节名推断发表时间、作者或页码。

怎样复核引用

每条记录标出篇章序号、JSON 文件名及 contentList 位置，并提供原始数据入口。正式引用前，应再核对对应出版物和上下文；图片卡片也不代替完整来源。
